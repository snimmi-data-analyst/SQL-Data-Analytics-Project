# SQL Data Analytics Project

## Project Overview
This project demonstrates an end-to-end SQL Data Analytics workflow using Microsoft SQL Server. It focuses on analyzing sales data, identifying business trends, understanding customer behavior, and generating meaningful business insights.

The project follows a structured approach to SQL-based data analysis and reporting.

## Objectives
- Analyze sales trends over time.
- Evaluate cumulative sales and business performance.
- Compare product performance.
- Understand sales contribution across different categories.
- Segment customers and products.
- Develop customer and product reports.

## Tools & Technologies
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL (T-SQL)
- Git & GitHub
